# 이미지 생성 응답 속도 비교

[웹 보고서 열기](https://hijigoo.github.io/image-latency-report/)

`quality=low`, 1024×1024 PNG 조건에서 일반 응답과 `partial_images=1`을 비교한 정적 보고서입니다.

- 일상 사진 생성, 전체 사진 스타일 변환, 얼굴·반려동물 캐릭터 변환의 3가지 작업
- 작업별·설정별 12회, 총 72회 측정
- 72개 최종 이미지와 34개 중간 미리보기, 공통 합성 입력 이미지
- 첫 미리보기·최종 완료 시간, 평균·분포·상대 차이, 이미지 확대 및 기록 재생

모든 이미지는 AI로 생성된 합성 이미지입니다. 공개본에는 필요한 측정값과 이미지 사본만 포함합니다. 내부 환경 식별자와 식별 메타데이터는 제외했으며, 수신 시간과 이미지 픽셀은 변경하지 않았습니다.

시간은 클라이언트 수신 시점 기준입니다. 특정 제공자·배포 환경은 공개하지 않으며, 이 탐색 실험은 다른 환경의 성능이나 운영 SLA를 보장하지 않습니다.

배포된 보고서는 저장소의 웹사이트 링크에서 볼 수 있습니다. `results.json`은 공개용으로 정리한 측정값이며, 이 저장소에는 API 호출 코드나 인증 정보가 없습니다.
